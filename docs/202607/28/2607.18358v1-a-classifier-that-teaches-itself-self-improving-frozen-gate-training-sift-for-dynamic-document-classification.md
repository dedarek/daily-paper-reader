## 摘要
文档分类在实验室中是一个已解决的问题，但在企业应用中却是一个未解难题。阻碍因素很少是模型架构，而是必须在模型构建之前进行的标注项目，以及一旦模型存在便让其自主重新训练的机构顾虑。我们提出了SIFT（Self-Improving, Frozen-gate Training，自改进冻结门训练），一种动态分类器服务，旨在攻克这两个难题。SIFT通过一条刻意设计的廉价CPU受限流水线提供分类服务，该流水线由SPLADE稀疏编码器馈入LightGBM头组成，并且仅将低置信度的少数页面升级至LLM裁判。裁判的判定结果会被写回标注语料库，因此昂贵的模型能够持续教导廉价的模型：升级率随之下降，语料库由生产流量而非前期标注工作不断扩充，且准确率随使用而复利增长。接入新的文档族仅需一个声明式包、标签空间、锚定短语和裁判术语表，而无需标注项目。更困难的问题在于安全性：自主重训练的分类器可能会悄然发生性能退化。SIFT通过一个由两部分组成的晋升门解决了这一问题：关键标签F1回归检查，加上一个模型从未在其上训练过的冻结黄金回归集，其中任一检查未通过都会否决模型晋升。这将“无需人工每月重训练”从鲁莽之举变为了常规操作。我们描述了该架构、自馈语料库循环、冻结门晋升机制以及一个说明性的多领域部署，并讨论了边际标注成本趋于零的分类器的经济学效益。

## Abstract
Document classification is a solved problem in the laboratory and an unsolved one in the enterprise. The blocker is rarely model architecture; it is the labeling project that must precede a model and the institutional fear of letting a model retrain itself once one exists. We present SIFT (Self-Improving, Frozen-gate Training), a dynamic classifier service, which attacks both. SIFT serves classification from a deliberately cheap, CPU-bound pipeline, a SPLADE sparse encoder feeding a LightGBM head, and escalates only the low-confidence minority of pages to an LLM judge. The judge's verdicts are written back into a labeled corpus, so the expensive model continuously teaches the cheap one: the escalation rate falls, the corpus grows from production traffic rather than from an up-front annotation effort, and accuracy compounds with use. Onboarding a new document family requires only a declarative bundle, label space, anchor phrases, and a judge glossary, not a labeling project. The harder problem is safety: an autonomously retraining classifier can silently regress. SIFT resolves this with a two-part promote gate, a critical-label F1 regression check plus a frozen golden regression set the model is never trained on, either of which vetoes promotion. This turns "retrain monthly without a human" from reckless into routine. We describe the architecture, the self-feeding corpus loop, the frozen-gate promotion mechanism, and an illustrative multi-domain deployment, and we discuss the economics of a classifier whose marginal labeling cost trends toward zero.

  1. **前置标注成本高**：构建模型前需要领域专家进行昂贵且耗时的标注项目（冷启动问题）。
  2. **自主重训的安全风险**：模型部署后会因数据漂移而衰退，但企业因担忧模型自主重训可能导致关键类别性能悄然退化（回归），而选择冻结模型任其腐烂。
* **整体含义**：本文旨在打破这一僵局，提出一种既能消除前置标注负担，又能保证自主重训绝对安全的动态分类框架，使分类器的边际标注成本趋近于零，让无人工干预的持续迭代成为安全常规。

## 2. 提出的方法论：核心思想、关键技术细节与流程
* **核心思想**：构建一个“廉价模型在前、昂贵模型在后”的级联架构。昂贵模型（LLM）仅作为“按小时雇佣的教师”，处理廉价模型无法决断的少数困难样本，其判定结果回写给廉价模型，实现“昂贵模型持续教导廉价模型”；同时引入“冻结门控”机制，确保自主重训不会引发关键性能退化。
* **关键技术细节**：
  * **成本分级服务**：使用 CPU 即可运行的 SPLADE（稀疏词特征编码器）+ LightGBM 组合作为廉价分类器，处理高置信度样本；仅将低置信度样本升级至 LLM 裁判。
  * **自馈语料库**：LLM 裁判的判定结果（高于最低置信度阈值）自动回写为标注数据；支持零数据冷启动（直接用 LLM 标注原始无标签页）；引入主动学习队列，将最不确定的样本优先交由人类专家审核。
  * **声明式领域包**：新文档类别的接入无需编写代码或标注项目，只需上传包含标签空间、锚定短语、正则包、裁判术语表和策略的 YAML 配置包。
  * **冻结门晋升机制**：候选模型必须同时通过两项检查才能替代线上模型，任一失败即否决晋升：
    1. **关键标签 F1 检查**：针对业务不可容忍误判的类别，候选模型在该类别的 F1 值不得低于当前模型。
    2. **冻结黄金回归集**：使用一个从未参与训练的固定金标数据集评估，候选模型在其上的表现不得下降。
* **算法/系统流程**：
  1. 请求进入，廉价模型（SPLADE+LightGBM）进行推理。
  2. 若置信度 >= 阈值，直接返回结果；若 < 阈值，升级至 LLM 裁判。
  3. LLM 裁判结果回写至语料库，人类也可通过主动学习队列修正并回写。
  4. 调度器根据行数、时间或漂移阈值触发重训练。
  5. 候选模型产生，接受“冻结门”双部件检查。
  6. 检查通过则自动晋升更新线上指针；未通过则留在待审核队列，等待人类干预。

* 冻结门控机制（关键类 F1 + 冻结金标集）有效杜绝了自主重训中关键类别的性能退化，使“无人工每月重训”成为安全配置。
* 新文档类别的接入从“昂贵的标注项目”降级为“声明式配置包上传”。

## 7. 优点
* **直击行业痛点**：精准识别出企业 AI 落地的真正阻碍并非算法精度，而是数据冷启动和迭代安全。
* **巧妙的级联与反哺设计**：将 LLM 视作“教师”而非直接分类器，既利用了其强大的零样本能力，又规避了其高延迟和高成本的缺陷。
* **工程落地性极强**：声明式领域包、多租户隔离、审计追踪、双保险门控机制，均高度契合大型企业（尤其是金融、医疗等受监管行业）的合规与运维要求。
* **经济学视角的创新**：将标注成本从“前置重资产投入”重塑为“随流量摊销的边际成本递减操作”。

## 8. 不足与局限
* **实验验证薄弱**：缺乏大规模、多领域的定量实验和消融研究，无法量化各模块（如 LLM 回写、冻结门控）的具体贡献幅度。
* **纯文本局限**：目前仅依赖 OCR 派生的文本，未融合视觉/版面特征，对于高度依赖排版而非文字的文档分类无能为力。
* **裁判偏见风险**：LLM 裁判的系统性偏差会被回写给廉价模型，导致“错上加错”。虽然冻结集和人工审核是兜底，但若裁判与金标集存在共同盲区，偏差将无法被发现。
* **冻结集的时效性**：冻结金标集是固定不变的，无法覆盖未来出现的新子类型文档，因此在应对真正新颖输入时，其作为“标尺”的效力会随时间衰减。
* **冷启动质量依赖人工配置**：零样本冷启动的质量高度依赖初始锚定短语和裁判策略的编写质量，配置粗糙会导致初始语料库噪声大、收敛慢。
